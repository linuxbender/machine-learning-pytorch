# Identify missing or unknown data values and convert them to NaNs.

# Parse the missing_or_unknown column from string to list
def parse_missing_codes(missing_str):
    if pd.isna(missing_str) or missing_str == '[]':
        return []
    missing_str = missing_str.replace('[', '').replace(']', '')
    if missing_str == '':
        return []
    codes = []
    for item in missing_str.split(','):
        item = item.strip()
        try:
            codes.append(int(item))
        except ValueError:
            codes.append(item)
    return codes

feat_info['missing_codes'] = feat_info['missing_or_unknown'].apply(parse_missing_codes)

Step 2.3: Interpret Principal Components¶

Now that we have our transformed principal components, it's a nice idea to check out the weight of each variable on the first few components to see if they can be interpreted in some fashion.

As a reminder, each principal component is a unit vector that points in the direction of highest variance (after accounting for the variance captured by earlier principal components). The further a weight is from zero, the more the principal component is in the direction of the corresponding feature. If two features have large weights of the same sign (both positive or both negative), then increases in one tend expect to be associated with increases in the other. To contrast, features with different signs can be expected to show a negative correlation: increases in one variable should result in a decrease in the other.

Key Findings:

Overrepresented Clusters (Target Customer Segments):

  • Certain clusters show significantly higher proportions in the customer data compared to the general population
  • These clusters typically represent:
    • Higher income/wealth individuals (based on HH_EINKOMMEN_SCORE, CAMEO_INTL_2015_WEALTH)

    • Homeowners and established households

    • Lower density/suburban or rural areas (EWDICHTE, INNENSTADT values)

Underrepresented Clusters (Non-Target Segments):

  • These clusters have lower proportions in customer data vs. general population
  • They typically represent:
    • Younger individuals (under 30-45)
    • Lower income households
    • Urban dwellers in high-density areas
    • More mobile or transient populations
    • People with less financial focus or different consumption patterns

Marketing Implications:

  1. Target Audience: The mail-order company attracts primarily older, financially stable, suburban/rural customers with traditional values
  2. Non-Target: Younger, urban, lower-income individuals are less likely to be customers
  3. Strategy Recommendation: Marketing campaigns should focus on the overrepresented segments, emphasizing reliability, quality, and traditional values rather than trendy or urban-focused messaging
